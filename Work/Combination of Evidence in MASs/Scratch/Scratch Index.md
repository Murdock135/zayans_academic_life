# Scratch index

Keep curated links to this project's scratchpads here. Group or annotate the links however you like. No required format beyond ordinary wikilinks.

Run **Index Checker: Check indexes** to check for missing scratchpad links. It is scoped to files named `Scratch Index`, so this file indexes its containing Scratch folder. Research Log indexes are automatic and are excluded. Review the marked files and use the plugin's add-missing-links action when you want to update this index.
